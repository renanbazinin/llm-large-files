# Eval baseline: 0.9.0

The baseline of the evals for 0.10.0: 49 questions in 41 chats (`evals/cases.ts`), on Gemini 3.5 Flash-Lite and Gemini 3.8 Flash over the Gemini API, three runs of each question (pass^3). Run on 2026-11-24 on commit 5fefdb3: the request bodies of 0.9.0 (package A of 0.10.0 changes no request byte; test/request-bodies.test.ts says so). Every later prompt change is compared with this.

- Run 1 of each model is the recording in `evals/cassettes`; runs 2 and 3 were live (`npm run eval:live -- --k 2`).
- Input tokens: 6,074,612 for the three runs of both models (Flash-Lite 3,226,176, Flash 2,848,436), plus about 2.0 million for a first recording pass that measured the cost and was recorded again after a fix to the language check. The cap was 25 million.
- "Cases passed in every run" is pass^3. A case passes when every fact of every question holds. "Cached share" is the provider's cached input tokens over all input tokens.
- The input-token ceiling was never reached: 0.9.0 has none by default.
- Citations are "not checked yet": `checkCitations` is not written in this version, so the `mustCite` facts and the citation figures wait for it.
- Answers are left out of this report, except the start of an answer whose fact failed. The files are synthetic (`evals/fixtures.ts`).
